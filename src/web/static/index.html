BEHIND THE PROJECT

Product data becomes
a decision-making tool.

An end-to-end research project by Anmol Saluja, built to connect competitor matching, price analysis and customer review evidence in a single interactive application.

01

Structure the catalogue

Clean and de-duplicate source listings, parse hardware specifications and organize products into market segments.

02

Make meaningful comparisons

Combine text embeddings and hardware similarity. Apply segment and price guards to keep competitor matches relevant.

03

Make findings inspectable

Show price coverage, analyse review aspects, and link generated answers to retrieved evidence with automated checks.

Read the results in context. This is a research snapshot of Amazon Reviews 2023, not a live shopping feed. Price statistics use listings with known prices; each chart reports its sample and coverage. Missing values stay unknown. Automated answer audits help identify errors, but do not guarantee that every answer is correct.
